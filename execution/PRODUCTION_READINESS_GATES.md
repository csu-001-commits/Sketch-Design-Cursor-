# PRODUCTION_READINESS_GATES — Sketch Design

بوابات جاهزية الإنتاج. الحالة: `DESIGNED` — **لم تُقيَّم أي بوابة بعد**.

---

## 1. القاعدة الحاكمة | The governing rule

**لا تُجتاز بوابة إلا بدليل مُنفَّذ ومرفق.**

- خطة ليست دليلًا. إجراء موثَّق ليس دليلًا. نية ليست دليلًا.
- `NOT_ASSESSED` حكم مستقل وصادق. **لا يُدمج في `PASS` أبدًا.**
- **حاجز واحد مفتوح يجعل الحكم الكلي `BLOCKED`** مهما اجتازت البوابات الأخرى.
- **لا تُحسب درجة مجمّعة.** المجموع يخفي الحاجز خلف متوسط، والمتوسط لا يُطلق منتجًا.

## 4. سلّم الحالات | Status ladder

`DESIGNED` → `IMPLEMENTED` (مرجع بناء) → `TESTED` (تشغيل اختبارات مرفق) → `VERIFIED` (إعادة إنتاج مستقلة).
و`BLOCKED` في أي نقطة، باسم الحاجز ومالكه وتاريخه.

**الترقية في اتجاه واحد وبدليل مرفق.** الحالة لا تُكتب لأن العمل «بدا مكتملًا».

## 5. كيف يُشتق الحكم | How the verdict is derived

```
verdict = BLOCKED  if any gate in {FAIL, NOT_ASSESSED}
        = READY    otherwise
```

يُشتق **آليًا** من جدول البوابات، ولا يُكتب يدويًا. `PASS` بمرجع دليل فارغ يفشل مدقّق التدقيق نفسه.

## 6. الحالة الحالية | Current standing

**الحكم الكلي: `BLOCKED`.**

لا تنفيذ. هذه ليست ملاحظة سلبية بل الحالة الصحيحة الوحيدة في هذه المرحلة: إعلان أي شيء سواها
سيكون بالضبط التلفيق الذي تمنعه هذه الوثيقة.
