# SERVICE_CATALOG — Sketch Design

كتالوج الخدمات المستهدفة، وحدودها، ومالك كل منها، والأمر الذي ينشئها.
جميع الخدمات في حالة `DESIGNED`: لا يوجد تنفيذ بعد، ولا تُرقّى حالة أي خدمة بلا دليل مُنفَّذ.

**تدفّق المعمارية الحاكم:**
`Frontend → API Gateway → Platform Services → Workflow Orchestrator → Engineering Agents → Model Gateway / Engineering Tools / Knowledge Services`

لوحة التحكم الإدارية تقع خارج زمن تنفيذ الوكلاء وتتصل بـ `Control Plane API` فقط.

## حدود لا تُنتهك | Boundaries that must not be violated

1. الواجهة الأمامية ولوحة الإدارة لا تستدعيان أداة وكيل ولا مفتاح مزوّد ولا جدول قاعدة بيانات مباشرةً.
2. لوحة الإدارة واجهة تحكم منفصلة؛ التصريح وموافقات التغيير تُفرض في الخادم.
3. زمن تشغيل الوكلاء ينفّذ قدرات مسجّلة تحت هوية مهمة محصورة وقائمة أدوات مسموحة.
4. بوابة النماذج خدمة إنتاجية مشتركة، ليست وكيلًا وليست ميزة متصفح.
5. الاسترجاع محكوم بالمصدر؛ المراجع الكودية تتطلب ترخيصًا وإصدارًا وتاريخ نفاذ واختصاصًا.
6. البيانات والتخزين والاسترجاع المتجهي وسجلات الأحداث والنسخ الاحتياطية تحترم حدود المشروع والمستأجر.

كل حد من هذه الستة يقابله اختبار آلي مسمّى في أمره، لا فقرة في وثيقة.
